# Khadamni

**Khadamni** is a platform connecting freelancers and clients to simplify job searches and task assignments. Built with Symfony, this project provides an intuitive interface for freelancers to find work and for clients to post tasks.

---

## Features
- **Freelancer Profiles**: Freelancers can create and manage their profiles.
- **Task Posting**: Clients can post tasks with detailed descriptions.
- **Search Functionality**: Freelancers can search for tasks based on skills, location, and budget.
- **Task Assignment**: Clients can assign tasks to freelancers.
- **User Authentication**: Secure login and registration system.
- **Admin Dashboard**: Admin panel for managing users, tasks, and platform settings.

---

## Technologies Used
- **Backend**: Symfony (PHP)
- **Frontend**: Twig, Bootstrap
- **Database**: MySQL
- **Authentication**: Symfony Security Component
- **Other Tools**: Composer, Doctrine ORM, Webpack Encore

---

## Installation

### Prerequisites
- PHP 8.1 or higher
- Composer (https://getcomposer.org/)
- MySQL 5.7 or higher
- Node.js and npm (for frontend assets)
